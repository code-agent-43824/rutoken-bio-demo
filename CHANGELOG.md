# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-09-24

### Added

- Demo web page for Rutoken Bio USB token: PIN login, key pair generation
  (with/without biometrics link), data signing, biometric login/logout/stop.
- Light rutoken.ru-style design (customer journey layout).
- GitLab CI/CD pipeline: `pages` (frontend copy on GitLab Pages) and
  `release` (tar archive → Package Registry → GitLab Release on tag).
- Project governance files: AGENTS.md, PLAN.md, CHANGELOG.md, CONTRIBUTING.md,
  LICENSE (BSD 3-Clause), .gitignore.
