# ROADMAP

## Продукт

Демонстрационная страница биометрического USB-токена **Рутокен Био**: посетитель
проходит путь от подключения устройства до электронной подписи и видит, чем
био-ключ отличается от обычного.

Публикуется на GitHub Pages: https://code-agent-43824.github.io/rutoken-bio-demo/

## Исходные требования владельца

1. Публичный репозиторий на GitHub.
2. Функции работы с био-токеном взять с референса https://aktivco.github.io/rutoken-plugin-demo/
3. Сценарии: вход по PIN, создание ключевой пары (с биометрией и без), подпись на ключе.
4. Три кнопки биометрии в правом верхнем углу: войти, выйти, остановить проверку.
5. Подпись на био-ключе сопровождается крупным попапом «коснитесь биометрического датчика».
6. Подпись на обычном ключе — сразу результат, без попапа.
7. Светлый дизайн в стиле rutoken.ru; не панель функций, а customer journey.

Требование «пока не деплоить» снято: публикация из корня ветки `main` включена.

## Стадии

| Стадия | Содержание |
| --- | --- |
| 1. Репозиторий | Публичный репозиторий, каркас страницы |
| 2. Интеграция с плагином | `window.rutoken`, устройства, PIN, ключи, подпись, биометрия |
| 3. Дизайн | Светлая тема rutoken.ru, пять шагов, журнал операций |
| 4. Диагностика | Трассировка вызовов API, подробные логи, защита журнала от секретов |
| 5. Правила и документы | Канонический свод правил, раскладка документов по §2 |
