# STATUS

Обновлено: 2026-09-14. Версия страницы: `BUILD_ID` = `2026-09-14.3` в `script.js`.

## Работает

Проверено на подменённом плагине (`node test.js`, прогон зелёный):

- загрузка плагина через `window.rutoken`, перечисление устройств и их профилей;
- вход и выход по PIN, распознавание кода 93 («вход уже выполнен»);
- список ключей по кнопке «Обновить» с пометками 🔬 / 🔑 / ❔;
- создание ключевой пары с биометрией и без, установка читаемой метки;
- удаление био-ключа по цепочке `isLoginBioRequired → loginBio(objectId) → deleteKeyPair → logoutBio`;
- подпись данных с попапом для био-ключа и без него для обычного;
- журнал операций с подробным режимом и копированием, без PIN и подписываемых данных.

## Не проверено

**На реальном токене Рутокен Био после правок диагностики страница не проверялась.**
`test.js` работает на фальшивом плагине — это проверка логики, а не заявление об
устройстве. Аппаратно зависимы прежде всего:

- предварительная проверка биометрии `preflightBioKey()` и ветка с неопределёнными
  счётчиками попыток (`confirmBioReady()`);
- поведение `setKeyLabel` сразу после генерации био-ключа;
- фактическое соответствие созданного ключа запрошенному типу (`verifyCreatedKey()`).
