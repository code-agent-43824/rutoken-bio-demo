## Работает

Проверено на подменённом плагине (`node test.js`, прогон зелёный):

- загрузка плагина через `window.rutoken`, перечисление устройств и их профилей;
- вход и выход по PIN, распознавание кода 93 («вход уже выполнен»);
- список ключей по кнопке «Обновить» с пометками 🔬 / 🔑 / ❔;
- создание ключевой пары с биометрией и без, установка читаемой метки;
- удаление био-ключа по цепочке `isLoginBioRequired → loginBio(objectId) → deleteKeyPair → logoutBio`;
- подпись данных с попапом для био-ключа и без него для обычного;
- журнал операций с подробным режимом и копированием, без PIN и подписываемых данных.

**Проверено владельцем на реальном токене Рутокен Био (2026-09-14): всё работает.**
Это относится и к аппаратно зависимым веткам — предварительной проверке биометрии
(`preflightBioKey()`, `confirmBioReady()`), установке метки сразу после генерации
био-ключа и сверке типа созданного ключа (`verifyCreatedKey()`).

Вёрстка после переосмысления дизайна проверена в Chromium на ширинах 1440, 1100, 900,
768 и 390 px: горизонтального скролла и перекрытий нет (`docs/PLAN.md`). Пять шагов идут
двумя строками, PIN показывается открытым текстом, список ключей обновляется сам после
создания и удаления, попап показывает отпечаток, который зеленеет при успехе.
