# Рутокен Био — Демонстрационная страница

Демонстрационная веб-страница для биометрического USB-токена **Рутокен Био**.
Показывает полный цикл работы: вход по PIN, создание ключевых пар с биометрией и без, подпись данных.

## Возможности

- 🔐 **Вход по PIN-коду** — аутентификация на токене
- 🗝️ **Создание ключевых пар** — с биометрической защитой и без
- ✍️ **Подпись данных** — на ключах с биометрией и без
- 🔬 **Биометрические кнопки** в правом верхнем углу:
  - «Войти по биометрии»
  - «Выйти по биометрии»
  - «Остановить проверку био»
- 📋 **Лог операций** — все действия записываются в консоль

## Использование

1. Откройте страницу в браузере с установленным Рутокен плагином
2. Подключите токен, выберите устройство
3. Войдите по PIN-коду
4. Создайте ключевую пару (с биометрией или без)
5. Введите данные и подпишите их

## Кнопки биометрии

В правом верхнем углу расположены три малозаметные кнопки:

| Кнопка | Действие |
|--------|----------|
| **Войти по биометрии** | Выполняет `plugin.loginBio()` — биометрический вход на токен |
| **Выйти по биометрии** | Выполняет `plugin.logoutBio()` — выход из био-сессии |
| **Остановить проверку био** | Выполняет `plugin.stopLoginBio()` — отмена текущей био-проверки |

## Сценарий подписи

При подписи данных на ключе:

- **Без биометрии**: подпись выполняется сразу после входа по PIN
- **С биометрией**: сначала проверяется `isLoginBioRequired`, затем при необходимости вызывается `loginBio` (показывается попап «коснитесь датчика»), после успешной биометрии выполняется подпись

## Технические детали

Используется `window.rutoken` API:
- `rutoken.ready` — проверка готовности
- `rutoken.isPluginInstalled()` — проверка установки
- `rutoken.loadPlugin()` — загрузка плагина
- `plugin.enumerateDevices()` — список устройств
- `plugin.getDeviceInfo()` — информация об устройстве
- `plugin.login()` / `plugin.logout()` — вход/выход по PIN
- `plugin.generateKeyPair()` — создание ключевой пары
- `plugin.enumerateKeys()` — список ключей
- `plugin.sign()` — подпись данных
- `plugin.isLoginBioRequired()` — проверка необходимости биометрии
- `plugin.loginBio()` / `plugin.logoutBio()` / `plugin.stopLoginBio()` — биометрия

## Запуск

```bash

python3 -m http.server 8000

# Или просто открыть index.html в браузере
```

## Требования

- Браузер с поддержкой Рутокен плагина (Chrome, Firefox, Edge)
- Установленный Рутокен плагин
- Подключённый токен Рутокен Био
