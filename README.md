# Рутокен Био — Демонстрационная страница

> ⚠️ **Внимание следующему агенту:** перед началом работы прочтите файл `AGENTS.md` — там подробно описано что сделано, почему и как. Это обязательное чтение.

## 📋 Описание

Веб-страница для демонстрации работы биометрического USB-токена **Рутокен Био**.
Страница предоставляет интерфейс для:

- 🔐 Входа на токен по PIN-коду
- 🗝️ Создания ключевых пар (с биометрической защитой и без)
- ✍️ Подписи данных с использованием созданных ключей
- 📋 Просмотра лога всех операций

## 🎯 Функциональность

### Основные возможности

| Функция | Описание |
|---------|----------|
| **Вход по PIN** | Аутентификация на токене через `plugin.login(deviceId, pin)` |
| **Выход** | `plugin.logout(deviceId)` |
| **Создание ключа** | `plugin.generateKeyPair(deviceId, undefined, marker, options)` с опцией `linkToBiometrics` |
| **Список ключей** | `plugin.enumerateKeys(deviceId, marker)` + `plugin.getKeyLabel(deviceId, keyId)` |
| **Удаление ключа** | `plugin.deleteKeyPair(deviceId, keyId)` |
| **Подпись данных** | `plugin.sign(deviceId, keyId, data, false, {addUserCertificate: true})` |

### Биометрические кнопки

В правом верхнем углу страницы расположены три малозаметные кнопки:

| Кнопка | Действие |
|--------|----------|
| **Войти по биометрии** | `plugin.loginBio(deviceId, {timeout: 30000}, callback)` — биометрический вход |
| **Выйти по биометрии** | `plugin.logoutBio(deviceId)` — выход из био-сессии |
| **Остановить проверку био** | `plugin.stopLoginBio()` — остановка текущей био-проверки |

### Сценарий подписи

При подписи данных на ключе:

1. Вызывается `plugin.isLoginBioRequired(deviceId, keyId)` для проверки необходимости биометрии
2. **Если биометрия требуется** (ключ создан с `linkToBiometrics`):
   - Показывается попап с иконкой отпечатка пальца и текстом «Приложите палец»
   - Вызывается `plugin.loginBio(deviceId, {objectId: keyId, timeout: 30000}, callback)`
   - После успешной био-аутентификации выполняется `plugin.sign()`
   - Если биометрия не пройдена — подпись отменяется
3. **Если биометрия не требуется** — подпись выполняется сразу через `plugin.sign()`

Результат подписи отображается в текстовом поле под кнопкой «Подписать».

```bash
python3 -m http.server 8000

```

## 📝 Технические детали

- **Без внешних зависимостей** — чистые HTML/CSS/JS, без фреймворков
- **Тёмная тема** — цветовая схема на CSS Custom Properties
- **Адаптивность** — grid-layout с медиа-запросами для мобильных устройств
- **IIFE-модуль** — весь JS обёрнут в IIFE для изоляции scope
- **CSS Custom Properties** — для лёгкого изменения цветовой схемы
