# Рутокен Био — Демонстрационная веб-страница

Демонстрационный лендинг для биометрического USB-токена **Рутокен Био**.

## Содержание

- **index.html** — главная страница с hero-секцией, описанием возможностей, интерактивной демо-симуляцией и техническими характеристиками
- **style.css** — стили в тёмной теме с акцентным цветом, анимациями и адаптивной вёрсткой
- **script.js** — интерактивная логика: симуляция сканирования отпечатка пальца с пошаговым отображением процесса аутентификации

## Возможности

- Адаптивный дизайн (mobile-first)
- Интерактивная демонстрация биометрической аутентификации
- Анимации сканирования, успеха и ошибки
- Без внешних зависимостей — чистые HTML/CSS/JS

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, анимации)
- Vanilla JavaScript (ES6+)
