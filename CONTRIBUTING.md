# Contributing

## Сборка и запуск

Проект — статический сайт без этапа сборки.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Для полного функционала нужен браузер с расширением «Адаптер Рутокен Plugin»
и подключённый токен Рутокен Био.

## Тесты

Автотестов нет. Минимальная проверка перед коммитом:

1. Страница открывается без ошибок в консоли браузера.
2. `node --check script.js` (если установлен node) — синтаксис JS валиден.

## Стиль кода

Следуйте `AGENTS.md` (правила веб-стека: 2 пробела, kebab-case для CSS,
camelCase для JS, IIFE + 'use strict', без внешних зависимостей).

## Коммиты и ветки

- Пушим напрямую в `main`, без feature-веток и MR.
- Сообщения коммитов — на английском, в императиве: `Add bio popup`, `Fix PIN login`.
- Релизы — пушем тега `vX.Y.Z` (SemVer); пайплайн собирает и публикует сам.
